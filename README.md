# Yolly Beach Resort

Static, responsive landing page. Open `index.html` directly, or run `node preview.cjs` and visit http://127.0.0.1:4174. No package installation or build is needed.

Rates, room information and phone/Facebook links live in `index.html`. Gallery photos and enquiry data live in `app.js`. Keep rate changes consistent in both files.

The enquiry form prepares a message for the visitor to send by SMS or copy to Facebook. It does not send messages, reserve rooms, check live availability, take payments or store guest information.

Enhanced photos are in `assets/`. Original resort photos remain in `Pictures/`; uploaded room photos are preserved as siblings in `assets/`. Exact ImageGen prompts and source provenance are recorded in `docs/photo-edits.json`. AI retouching cleans clutter and lighting while retaining the original property.

Mobbin references could not be retrieved because its MCP requires a paid plan. This is an original design based on the property and the user's brief.
